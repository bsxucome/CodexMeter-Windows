# CodexMeter for Windows 0.7.4

本次更新优化设置和管理页面的视觉层次。

- 设置、高级外观、远程提醒、历史与备份、关于页面统一使用柔和灰色表面，去除突兀的大块纯白底色。
- 排序列表改用圆角容器、宽松行距与淡色选中态；列表高度随内容变化，减少无用留白。
- 输入框与密码框统一圆角边框及键盘焦点提示，下拉选项适配浅色与深色主题。
- 高级外观及通知参数使用细线轨道和圆形滑块，深色模式不再出现突兀的白色滑轨。
- 保存、应用和完成等底部主要操作使用强调色，预览及次要按钮使用低对比度灰底。
- 保留设置与高级外观隐藏滚动条、列表内滚轮交接、键盘翻页及固定底栏行为。

推荐选择 `CodexMeter-Windows-0.7.4-dotnet10-x64.zip`；Framework 兼容包需要 .NET Framework 4.8 或更新版本。两者均为 Windows x64 便携包。

升级前请在旧版主面板点击“退出”，将新版完整解压到独立目录，再运行 `CodexMeter.exe`。设置与历史记录可继续使用。
