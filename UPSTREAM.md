## Checkout limitation

Shell networking to GitHub was unavailable during implementation, so git clone did not succeed. No upstream commit SHA was verified; browser-cached pages are not a reliable current HEAD. This directory is deliberately not presented as a complete clone or an upstream-aligned patch.

When network access is available, run `windows/scripts/sync-upstream.ps1 -Reference main`, inspect the recorded commit and its guide, and review all remaining quota/UI differences against that checkout. This retrieval alone is not completed parity review. For an upstream pull request, preserve the macOS sources and integrate the Windows directory and documentation into a full clone.
