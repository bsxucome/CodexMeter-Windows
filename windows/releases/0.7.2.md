# CodexMeter for Windows 0.7.2

本次更新包含设置体验改进，并修复仓库改名后 Windows 自动构建中的测试路径过长问题。

## 更新内容

- 高级外观与设置页统一为 380 DIP 紧凑窗口，统一标题、边距和按钮。
- 隐藏高级外观与设置页的竖向滚动条，保留滚轮和键盘翻页；高级外观的实时预览与底部操作固定显示。
- 修复鼠标停在设置排序列表内时无法滚动页面的问题；长列表先滚动内部内容，到边界后接续页面滚动。
- 外观参数分组显示，中英文及浅色／深色界面适配窄窗口。
- 修复 Framework 测试生成 npm 模拟目录时触及 Windows 旧路径长度限制的问题。保留中文、空格、完整随机标识与 npm 原生程序／Node 回退覆盖。
- 为 Actions 增加云端目录长度回归检查；版本标签继续自动触发构建、测试、打包和 Release 发布。
- 项目主页默认中文，并提供英文介绍入口。

## 下载与升级

- 推荐下载 `CodexMeter-Windows-0.7.2-dotnet10-x64.zip`，自带 .NET 运行时。
- `CodexMeter-Windows-0.7.2-framework-x64.zip` 体积更小，需要 .NET Framework 4.8 或更新版本。
- 两种包面向 Windows x64，每个 ZIP 均附 SHA-256 校验文件。
- 先在旧版主面板底部点击“退出”，再将新版完整解压到新目录，运行 `CodexMeter.exe`。仅关闭设置窗口不会退出旧实例。
- 当前用户的设置与历史保存在独立的本地应用数据目录，可继续使用。高级外观修改仍需先应用到设置，再保存设置。

## 使用范围

当前发布便携包，正式代码签名证书、更新签名密钥和应用内更新源仍未配置。请通过 GitHub Release 下载升级。

任务栏采用独立覆盖窗口；真实 Explorer、多屏缩放、自动隐藏及物理触控板行为仍需对应环境验收。该项目是参考上游 CodexMeter 的独立 Windows 社区实现。
