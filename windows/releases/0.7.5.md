# CodexMeter for Windows 0.7.5

本次更新修复任务栏双环与详情面板的显示问题。

- 主面板、设置、高级外观、历史及其他功能窗口统一显示完整名称 **CodexMeter for Windows**，并同步窗口标题、托盘提示与中英文界面。
- 修复定位检查重复显示双环窗口的问题；位置不变时不再反复发送原生定位请求，隐藏状态由应用明确控制。
- 任务栏取得焦点并遮住双环时，及时恢复覆盖层顺序，不通过隐藏再显示处理。
- 不完整的任务栏测量不会覆盖已有的稳定位置，避免从任务栏内来回跳到回退位置。
- 详情面板在首次显示前准备目标屏幕 DPI、测量内容并确定位置；按目标工作区限制边界，双环移动时详情同步跟随。
- 保留 0.7.4 的柔和灰底、圆角控件、圆形滑块、隐藏滚动条及固定底部操作。

推荐下载 `CodexMeter-Windows-0.7.5-dotnet10-x64.zip`；Framework 兼容包需要 .NET Framework 4.8 或更新版本。两者均为 Windows x64 便携包，并附 SHA-256 文件。

升级前先在旧版主面板点击“退出”，完整解压新版到新目录，再运行 `CodexMeter.exe`。应用数据目录、偏好设置和历史记录保持兼容。

真实 Explorer 点击、多屏混合缩放与任务栏自动隐藏仍需对应桌面环境验收；隔离回归覆盖首次可见边界、重复定位消息、布局跟随和缩放几何。
