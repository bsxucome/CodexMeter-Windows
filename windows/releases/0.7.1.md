# CodexMeter for Windows 0.7.1

本次更新重点改进设置页与高级外观的使用体验，并完善中文项目介绍和 GitHub Actions 发布流程。

## 更新内容

- 高级外观与设置页统一为 380 DIP 紧凑窗口，统一标题、边距、分隔线和按钮样式。
- 隐藏高级外观右侧滚动条，保留滚轮与键盘翻页；顶部实时演示预览、底部应用与导入导出按钮固定显示。
- 外观参数按图形、文字与颜色分组，中英文及浅色／深色界面均适配窄窗口。
- 修复鼠标停在设置页排序列表内时页面无法滚动的问题。较长列表先滚动内部内容，到边界后接续页面滚动；保留列表选择与排序。
- 隐藏设置页及排序列表的竖向滚动条，移除右侧多余留白。
- 项目展示名称统一为 CodexMeter for Windows，默认中文介绍，并提供英文入口。
- GitHub Actions 支持版本标签触发构建、测试、打包和 Release 发布，也支持手动选择 release 在同一次运行中完成发版。

## 下载与升级

- 推荐下载 `CodexMeter-Windows-0.7.1-dotnet10-x64.zip`，自带 .NET 运行时。
- `CodexMeter-Windows-0.7.1-framework-x64.zip` 体积更小，需要 .NET Framework 4.8 或更新版本。
- 两种包均面向 Windows x64，主要验证环境为 Windows 11；每个 ZIP 附带 SHA-256 校验文件。
- 先在旧版主面板底部点击“退出”，再将新版完整解压到新目录并运行 `CodexMeter.exe`。仅关闭设置窗口不会退出程序；旧版仍运行时，点击新版会唤起旧实例。
- 当前用户的设置与历史记录保存在独立的本地应用数据目录中，升级时可继续使用。高级外观修改后，仍需先“应用到设置”，再在设置页保存。

## 使用范围

本次发布便携包。正式代码签名证书、更新签名密钥及应用内更新源仍未配置，请从 GitHub Release 下载升级。

任务栏显示采用独立覆盖窗口；真实 Explorer、多屏缩放、自动隐藏及物理触控板行为仍需对应环境验收。该项目是参考上游 CodexMeter 的独立 Windows 社区实现。
