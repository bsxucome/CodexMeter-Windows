# CodexMeter for Windows 0.7.7

- 推荐的 .NET 10 自包含包改为单文件发布，无需安装 .NET；解压后直接双击 CodexMeter.exe。
- 根目录只保留程序、使用说明.txt 和 docs，详细指南、许可证及验证记录集中存放。
- Framework 兼容版继续提供，保留必需的 Core DLL 与配置文件。
- 关于页面支持新文档目录，并兼容旧版许可证位置。
- 更新校验兼容 .NET 单文件和旧多文件清单；仍严格校验签名、运行时、通道及全部文件哈希。
- Actions 增加实际发行包的布局与解压启动验证，覆盖中文／空格路径，以及单文件更新启动、失败回退和篡改拒绝。

升级请先退出旧版，完整解压到独立目录，设置与历史会保留。从旧版首次切换请手动下载；旧更新器会要求独立 Core DLL。单文件仍包含运行时，体积不会因此显著降低，首次启动可能向系统临时目录释放原生依赖。

正式签名清单、公钥和代码签名证书尚未上线，当前通过 GitHub 发行页手动下载。真实 Explorer、自动隐藏和混合 DPI 场景仍需实机验收。
