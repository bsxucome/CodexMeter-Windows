# CodexMeter for Windows 0.7.0

首个 Windows 开源发行版，提供任务栏双环与百分比、托盘入口和额度详情面板。

## 下载与运行

- 推荐下载 `CodexMeter-Windows-0.7.0-dotnet10-x64.zip`：自带 .NET 运行时，无需额外安装 .NET。
- `CodexMeter-Windows-0.7.0-framework-x64.zip`：体积更小，需要 .NET Framework 4.8 或更新版本。
- 两种包均面向 Windows x64，主要验证环境为 Windows 11。退出旧版本后，完整解压 ZIP，再运行 `CodexMeter.exe`。
- 额度读取需要已安装并登录的 Codex CLI；应用通过本地 App Server 通信。首次运行可在设置中选择 CLI 路径。
- 每个 ZIP 都附有 `.sha256` 校验文件。设置和历史记录独立保存于当前用户的本地应用数据目录。

## 包含功能

- 任务栏双环、百分比、横条等五种显示样式，可调整外观与开始按钮附近的位置。
- 五小时／每周额度、重置倒计时、消耗节奏，以及服务端提供的可选余额与重置机会。
- 额度历史、Token 活动、图表、CSV 导出、本地备份与恢复。
- 低额度通知、可选远程提醒、登录启动及中英文界面。
- 可配置的 Windows 更新检查、签名清单校验与启动失败回退。
- 修复圆环点击与面板重开、UTF-8 通信、损坏设置恢复及 Windows 自动构建问题。

## 使用范围

任务栏显示采用独立覆盖窗口，当前以主屏横向任务栏为目标。多屏缩放、自动隐藏及实际 Explorer 行为仍需继续验收。应用为参考上游 CodexMeter 的独立 Windows 社区移植，不是 OpenAI 官方产品，也不宣称已完全对齐 macOS 版本。

当前未配置正式代码签名证书和更新签名密钥，发布便携包；应用默认更新源保持空白。后续签名更新源接入方式见仓库的 `windows/RELEASES.md`。
