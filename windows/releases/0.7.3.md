# CodexMeter for Windows 0.7.3

本次更新包含设置页与高级外观体验修复，并补齐 Windows 自动发布的兼容性检查。

## 更新内容

- 高级外观与设置页统一为 380 DIP 紧凑窗口，隐藏竖向滚动条，保留滚轮和键盘翻页。
- 高级外观的实时预览与底部操作固定显示，参数分组适配中英文和浅深色界面。
- 修复设置排序列表截住页面滚轮的问题；长列表在边界处接续外层页面滚动。
- 修复仓库改名后 Framework 测试目录超过旧路径长度限制的问题。
- 将 Actions 签名步骤迁移至带 UTF-8 BOM 的独立脚本，修复 Windows PowerShell 对中文内联脚本的解码错误；未配置密钥时正常发布便携包。
- 增加实际工作流入口的无密钥及测试密钥签名回归，覆盖两种运行时、稳定版和测试版清单。
- 改进界面测试就绪等待：等待应用输入空闲，按窗口句柄刷新自动化对象，在有界时间内等待控件出现；缺失控件仍会使测试失败。
- 版本标签继续自动触发构建、测试、打包与 GitHub Release 发布。

## 下载与升级

- 推荐下载 `CodexMeter-Windows-0.7.3-dotnet10-x64.zip`，自带 .NET 运行时。
- `CodexMeter-Windows-0.7.3-framework-x64.zip` 体积更小，需要 .NET Framework 4.8 或更新版本。
- 两种包均为 Windows x64 便携版，每个 ZIP 附带 SHA-256 校验文件。
- 先在旧版主面板底部点击“退出”，再将新版完整解压到新目录并运行 `CodexMeter.exe`。仅关闭设置窗口不会退出旧实例。
- 设置与历史记录保存在当前用户独立的本地应用数据目录，可继续使用。高级外观修改后仍需应用到设置并保存。

## 使用范围

正式代码签名证书、更新签名密钥及应用内更新源仍未配置。测试使用的临时密钥仅用于隔离验证，不用于正式发行；请通过 GitHub Release 下载升级。

任务栏采用独立覆盖窗口；真实 Explorer、多屏缩放、自动隐藏及物理触控板行为仍需对应环境验收。该项目是参考上游 CodexMeter 的独立 Windows 社区实现。
