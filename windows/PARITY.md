## 分阶段顺序

1. **v0.3.0（已交付）**：历史与 Token 的基础能力，五种显示样式、内容开关／排序与三语言。
2. **v0.4.0（已交付）**：日历导航、长期 Token 汇总、消耗与预测、平滑曲线和空档阴影、每周小图、高级外观参数。
   v0.4.1 修正详情弹窗的系统滚动条：隐藏外观并保留滚动，固定标题与底部操作。
   v0.4.2 修正透明像素点击穿透，释放鼠标捕获后打开详情，补齐捕获中断恢复与重复打开处理；实际 Explorer 点击仍需验收。
3. **v0.5.0（已交付）**：第 1–3 阶段的任务栏稳定性、显示与额度、通知与登录启动。211 项自动测试；实际 Explorer 和系统交付仍待验收。
4. **v0.6.0 第 4 阶段**：四渠道远程提醒、Windows 用户加密存储、实际补充判定、重试／取消与测试隔离已接入。
5. **v0.6.0 第 5 阶段**：完整历史备份恢复、全账号管理、替换失败回滚、采集暂停与恢复已接入。
6. **v0.6.0 第 6 阶段**：关于、可配置 Windows 更新、签名与哈希校验、启动回退、自动构建和发布脚本已接入。后续已建立公开发行仓库并发布 0.7.0；0.7.6 预设本仓库 GitHub 更新地址，正式签名清单、信任公钥与证书尚未配置。上线发行源并完成实机验收后，再复核完整功能表。

## 验收原则

- 以原项目已发布行为为基准；Windows 原生差异写清楚，不把浮层描述成 Explorer 内嵌控件。
- 统计数据必须来自服务或本地真实采样。CLI 不支持的可选接口单独标为不可用。
- 账号切换立即清空当前显示，迟到响应不能写入另一个账号或恢复旧数据。
- 预览不启动 CLI、不读写正式历史、不保存偏好；界面必须标记演示数据。
- 每次更新记录代码检查、交互检查、实机未验收项与可下载产物。
